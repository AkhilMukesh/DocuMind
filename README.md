# DocuMind
AI document assistant that lets a user upload documents and ask questions in natural language, while returning answers grounded in the documents.



Companies have thousands of documents:
HR policies
Insurance documents
Technical manuals
SOPs
Product documentation
Legal documents
Internal knowledge bases etc..

Employees often waste time manually searching through these documents.

We want to build:

An AI document assistant that lets a user upload documents and ask questions in natural language, while returning answers grounded in the documents.
